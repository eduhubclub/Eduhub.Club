# Edu.Hub

A repository for Edu.Hub — the one-stop shop for education.

## Layout

- `web/` — the live React + Vite + Tailwind app (run from here)
- `reference/` — historical `.txt` source dumps used while building early apps; **not** the live code and safe to remove later
- `quiz-tester.html` — standalone quiz experiment at the repo root

## Run

```bash
cd web
npm install
npm run dev
```
