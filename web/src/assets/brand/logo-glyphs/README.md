# Logo glyphs

Source files for Edu.Hub logo marks, mirrored from `SVG/` (`Default/`, `Outline/`, `Textured/`, `Scribbles/`).

| Folder | Contents |
|--------|----------|
| `default/` | Circle, Triangle, Square, Scribble (3pt) — flat fills |
| `outline/` | Same four glyphs as outline art |
| `textured/` | Same four glyphs with textured fills (`Squiggle.svg` → `scribble.svg`) |
| `scribbles/` | Scribble variants: `3pt`, `2pt`, `1`–`5`, `circular`, `dense`, `shading` |

Brand colors (when using Default fill marks): circle rose-500 · triangle amber-500 · square emerald-500 · scribble sky-500.

App usage: `logoGlyphs.jsx`, `logoScribbleVariants.js`, `logoGlyphStyleMarks.jsx`, `Logo.jsx`.
HubBrand → Logo Test: scribble picker (Default style) + Style (Default / Outline / Textured).
